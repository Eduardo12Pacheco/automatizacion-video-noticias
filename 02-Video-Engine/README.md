<h1 align="center">Video Engine</h1>

Video Engine is the Remotion final-render runtime for contracts generated by `01-Control-Panel`. The supported path receives `composition-contract.json` plus localized assets under `projects/<id>`, adapts that contract to Remotion props, and writes the final MP4.

## Official render-only flow

```txt
01-Control-Panel approval
  -> services/approval-editor/lib/video-engine-render-adapter.js
  -> projects/<id>/composition-contract.json + public assets
  -> node scripts/render-video.js --project-root=projects/<id> --profile=final
  -> projects/<id>/output/video-final.mp4
```

Safe happy path from this folder:

```bash
node scripts/render-video.js --project-root=projects/<id> --profile=final
```

Expected output:

- `projects/<id>/output/video-final.mp4`

`scripts/render-video.js` is the stable public wrapper used by Control Panel. Keep it available while cleanup continues.

## Deletion boundary for legacy cleanup

This cleanup deletes only high-confidence manual pipeline code and resources that are not on the official render-only path.

| Status | Paths |
|--------|-------|
| Deleted in this work unit | root manual JS wrappers, the old manual pipeline implementation directory, and archived/demo pipeline resources |
| Deferred, still present | `scripts/transcribe-audio.py`, local approval service files, transitional `scripts/lib/*` compatibility wrappers, editor/timeline render fallbacks |
| Hard keep | `scripts/render-video.js`, `scripts/render/render-video.js`, `scripts/lib/contracts/composition-contract.js`, `src/remotion/`, and `assets/overlays/` |

Safe deletion criteria for future work:

- The file is outside Control Panel -> render wrapper -> render implementation -> composition contract -> Remotion `MyComp`.
- Control Panel does not call it directly; `scripts/transcribe-audio.py` remains because alignment still uses it.
- It is not a render asset or overlay required by final render fidelity.
- Focused checks prove the deletion or the old test existed only for deleted behavior.

## Safe checks for this boundary

Use focused Node checks only:

```bash
npm run check:render-boundary
node --test tests/approval-editor-service-v1.test.js tests/composition-contract.test.js tests/editor-contracts.test.js tests/cover-pan-layer.test.js
node scripts/render-video.js --project-root=<temp-project> --profile=final --dry-run
```

Do not run builds, heavy Remotion renders, model/CUDA/audio generation, or visual exports for this cleanup check.

## Assets required for local final render

```txt
assets/overlays/
```

Do not delete `projects/draft-*` or `assets/overlays/` from a local environment without explicit confirmation and a migration plan.
