# RSS/Atom fixtures

Shared by the Node adapter tests (`packages/adapters/test/rss.test.js`) and the
Python monitor tests (`services/channel-monitor/tests/test_rss_client.py`) so
both parsers are validated against the same public feed shapes.

- `youtube-channel-feed.xml` — public YouTube channel Atom feed (RSS path).
- `google-news-feed.xml` — Google News RSS response (news discovery path).
