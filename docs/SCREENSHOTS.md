# Screenshots

Every view of the panel in Spanish and English, at desktop (1440 x 900) and
mobile (390 x 844) sizes. The shots are written by the visual-QA suite
(`e2e/visual-qa.spec.js`), which runs against the showcase panel without Docker;
regenerate them with `node tools/run-visual-qa.mjs` (see the Visual QA section of
[e2e/README.md](../e2e/README.md)).

For a moving version, recorded from the running demo-mode stack with the seeded
fictional story, see the [demo GIF](images/demo.gif) and the
[67-second MP4](images/demo.mp4).

In each table the top row is desktop and the bottom row is mobile; the left
column is the Spanish UI and the right column is the English UI.
